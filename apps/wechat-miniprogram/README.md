# 糖迹微信小程序（个人备案版）

这是糖迹面向个人用户的原生微信小程序版本，定位为“个人健康数据记录工具”。小程序和手机 Web 共用现有 API 与数据库，但分别维护各自的页面入口：

- 小程序：仅提供微信登录、四类数据记录、历史、统计、导出、回收站和账号注销。
- 手机 Web：继续承担完整用户端功能。
- 管理控制台及现有业务接口不受小程序版本调整影响。

小程序目录不包含需要特殊行业资质的服务入口或相关页面。提交审核时只上传本目录中未被 `project.config.json` 排除的运行文件。

## 本地预览

1. 使用微信开发者工具导入 `apps/wechat-miniprogram`。
2. 默认连接生产 API：`https://tangji.aiteam.pw`。
3. 生产 API 必须设置 `WECHAT_MOCK=false`，并正确配置 `WECHAT_APPID` 和 `WECHAT_SECRET`。
4. 开发者工具已启用合法域名校验，预览前应先完成下方平台配置。

## 微信公众平台配置

提交体验版或正式版前，需在微信公众平台完成：

1. 服务类目选择 `工具 → 健康管理`。
2. 备案服务内容选择 `生活服务 → 工具 → 健康管理`。
3. 将 `https://tangji.aiteam.pw` 同时添加为 `request` 和 `downloadFile` 合法域名。
4. 在“用户隐私保护指引”中如实声明微信账号标识、用户主动选择的头像和昵称，以及用户主动填写的性别和健康记录数据。
5. 隐私保护指引中的运营主体、联系方式、信息用途和本地《隐私政策》保持一致。
6. 上传前确认服务器 TLS 证书有效，且正式环境微信登录配置可用。

## 审核说明建议

审核备注可说明：本小程序仅供用户记录本人血糖、血压、血脂和尿酸数据，查看个人历史与趋势，并支持数据导出和账号注销；不提供线上问诊、诊断、治疗、商品交易或个性化处置方案。

体验流程：阅读并勾选协议 → 微信一键登录 → 记一笔 → 查看历史/统计 → 我的页面导出或注销账号。微信登录无需另行提供测试账号。
